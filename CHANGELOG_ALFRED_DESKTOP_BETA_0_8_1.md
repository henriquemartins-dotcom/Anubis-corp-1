# ALFRED Desktop Beta 0.8.1

## Novidades
- Tela de abertura animada antes do login com vídeo institucional da Anubis.
- Botão **Pular** para seguir direto ao login.
- Transição suave da abertura para a tela de login.
- Fallback automático para não bloquear o acesso caso o vídeo não carregue.

## Observações
- O splash é exibido antes da autenticação do sistema.
- O login por senha e a área de relatórios salvos continuam ativos.
