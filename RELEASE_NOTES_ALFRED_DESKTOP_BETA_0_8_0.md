# Release Notes - ALFRED Desktop Beta 0.8.0

A Beta 0.8.0 consolida o ALFRED como aplicativo interno protegido, com abertura profissional e acesso centralizado aos documentos gerados.

## Destaques

1. **Login por senha:** o ALFRED agora exige autenticação antes de exibir os dados.
2. **Tela de abertura:** uma apresentação nativa acompanha a inicialização do sistema.
3. **Relatórios salvos:** todos os PDFs podem ser consultados diretamente no novo módulo Relatórios.

## Primeiro acesso

```text
Usuário: henrique
Senha: alfred123
```

Após entrar, abra **Configurações** e cadastre uma senha própria.

## Atualização

Feche a versão anterior, extraia a Beta 0.8.0 em uma pasta nova e execute `TESTAR_DESKTOP_WINDOWS.bat`. A base, os editais, checklists e relatórios permanecem na pasta local do ALFRED.
