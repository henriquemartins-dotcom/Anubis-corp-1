# Release Notes - ALFRED Desktop Beta 0.7.1

Esta atualização adiciona a exportação completa do checklist de cada edital para PDF.

## Como usar

1. Abra um edital e acesse **Checklist**.
2. Gere o checklist com IA, caso ainda não exista.
3. Atualize status, responsáveis e observações.
4. Clique em **Baixar checklist PDF**.

O arquivo será baixado e também permanecerá na pasta local de relatórios do ALFRED.

## Conteúdo do PDF

- fato do edital;
- alerta central;
- dados do certame;
- andamento geral;
- itens separados por categoria;
- responsáveis, controles e referências;
- próximos passos;
- recomendação operacional.

Os dados persistentes das versões anteriores são preservados.
