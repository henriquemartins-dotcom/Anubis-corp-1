# Release Notes - ALFRED Desktop Beta 0.7.0

A Beta 0.7.0 transforma o acompanhamento de licitações em um fluxo mais preventivo e documentado.

O ALFRED agora interpreta os documentos de cada edital para montar um checklist operacional, executa buscas diárias de novas concorrências e gera relatórios PDF das oportunidades selecionadas ou encontradas pelo monitoramento.

## Destaques

- Checklist por edital construído pela IA.
- Monitoramento diário do PNCP com filtros configuráveis.
- Relatórios executivos em PDF.
- Agendamento no Windows mesmo com a janela do ALFRED fechada.
- Integração com o Pipeline e Mission Control.

## Atualização

Feche a versão anterior e extraia a Beta 0.7.0 em uma pasta nova para teste. A base persistente continuará em `%LOCALAPPDATA%\Anubis\ALFRED`.
