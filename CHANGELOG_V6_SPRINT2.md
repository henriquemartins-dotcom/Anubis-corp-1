# Danza Licita IA 6.0 — Sprint 2

## Entregas
- Dashboard executivo redesenhado com indicadores de oportunidades abertas, prazos críticos, taxa de indexação, valor potencial e ticket médio.
- Radar Nacional 2.0 com pesquisa, filtros por UF, modalidade e situação, além de favoritos locais e score preliminar de aderência.
- Tema claro/escuro persistente.
- Mapa de calor por estado com navegação direta para o radar filtrado.
- Ranking de órgãos contratantes e modalidades.
- Nova experiência responsiva para desktop e dispositivos móveis.
- API de dashboard ampliada com indicadores operacionais.
- API de editais ampliada com filtros, preservando compatibilidade com chamadas existentes.

## Compatibilidade
- Rotas antigas preservadas.
- Sincronização PNCP, retomada, cancelamento, upload e análise RAG mantidos.
- 14 testes automatizados aprovados.
