# Release Notes — ALFRED Desktop RC 0.6.1

O ALFRED agora acompanha o ciclo completo das licitações em um pipeline operacional. Cada edital pode ser priorizado, atribuído a um responsável, movimentado entre etapas e acompanhado por histórico.

## Destaques
- Pipeline Kanban integrado ao Radar e ao Mission Control.
- KPIs executivos baseados em dados reais.
- Alertas visuais para prazos críticos.
- Histórico de decisões e movimentações.
- Dados mantidos localmente no computador.

## Compatibilidade
- Windows 10 e Windows 11 x64.
- Atualização compatível com a base local das versões Desktop Beta 0.5.x.
