# ALFRED Executive Intelligence — Desktop Beta 0.5

A primeira edição desktop do ALFRED foi preparada para uso interno em computadores Windows 10/11.

## Funcionalidades disponíveis

- Mission Control;
- Radar de licitações e sincronização PNCP;
- base de editais, pesquisa e filtros;
- edição e exclusão de editais;
- favoritos;
- upload e indexação de documentos;
- perguntas ao ALFRED em modo local ou OpenAI;
- indicadores, histórico e acompanhamento das sincronizações;
- backup local.

## Estado da versão

Esta é uma versão **Beta**. Recomenda-se testar inicialmente em um computador e manter backups frequentes antes de distribuir para toda a equipe.
