# ALFRED Alpha 0.1 — Release Notes

Esta é a primeira versão da nova identidade do produto.

## Destaques

1. **Mission Control** reúne indicadores, prioridades e recomendações em uma única visão executiva.
2. **Executive Advisor** classifica as oportunidades disponíveis e destaca a mais aderente.
3. **Operational Health** apresenta uma leitura simples da prontidão da base e dos prazos críticos.
4. A navegação foi reorganizada sob a marca **ALFRED Executive Intelligence**, desenvolvida pela **Anubis Corp**.

## Como executar

### Docker

```bash
docker compose up --build
```

Acesse `http://localhost:8000`.

### Windows

Execute `instalar_windows.bat` na primeira utilização e depois `iniciar_windows.bat`.

## Observação

A Alpha 0.1 é uma fundação de produto. As integrações com Omie, Publi, Bitrix24, Gmail e Google Drive permanecem planejadas para versões posteriores.
