# Release Notes — ALFRED Desktop RC 0.6.1

Esta é a primeira versão candidata a distribuição interna por instalador Windows. Ela mantém o Mission Control, Radar, Base de Editais, Ask Alfred, Alfred Docs e Pipeline de Licitações da versão 0.6.0, acrescentando uma rotina profissional de instalação e atualização.

O instalador não remove os dados operacionais existentes.
